## The line

> Your future self is already debugging the shortcut you are about to take.

73 characters, one line. A small prophecy about what is coming: the
shortcut you are about to take is already being debugged by your
future self. It is true about a developer's day — shortcuts become
the bugs someone has to debug — and the twist is the tense: the
debugging has already started, before the shortcut is even taken.

## How it works

`main.py` (Python 3.13 standard library only, no network) writes the line
to `/output/entry.txt`:

```sh
python3 main.py
```

It self-checks the competition gate first: 1–120 characters, a single line,
not only whitespace. The output is deterministic — every run writes the
exact same bytes.
